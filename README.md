# loosi&pashmak&kooki

Initial Android milestone: a native Android app shell with a map that requests location permission and displays the phone's current GPS/network position. Map tiles require internet access.

Important: this version displays the phone location only. It does not locate a bird or communicate with a tracking device. A later hardware milestone must define the radio/network protocol, battery, antenna and safe attachment method. Do not attach a prototype to a bird before an avian veterinarian reviews its weight and attachment safety.

To build, run the Build Android APK workflow in GitHub Actions. Download the loosi-pashmak-kooki-apk artifact and extract the APK from its ZIP.
